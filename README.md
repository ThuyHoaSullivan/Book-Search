# Book Search Engine

## Overview

This project refactors a Google Books API search engine built with a RESTful API to use GraphQL for querying and modifying data. The app was originally built using the MERN stack with a React frontend, MongoDB for the database, and Node.js/Express.js for the backend. The goal of this project is to integrate Apollo Server for GraphQL, allowing users to save and view book searches.

## Features:

* Search for books using the Google Books API.
    
* Save search results to the backend for later reference.

* User authentication using JWT for secure login and registration.

* GraphQL queries and mutations for managing data.

## Technologies Used:

React – Frontend

Node.js – Backend

Express.js – API layer

MongoDB – Database (MongoDB Atlas)

Apollo Server – GraphQL API server

Apollo Provider

JWT – Authentication

Mongoose – MongoDB ORM
